# MJ Virtuel

Assistant de Maître du Jeu pour parties de jeu de rôle. Application statique, sans backend.

## Utilisation
1. Ouvrir le site.
2. Renseigner l'univers, le ton et les personnages.
3. Optionnel : `Paramètres` pour brancher une clé API (Gemini ou OpenAI compatible).
4. Écrire l'action du joueur et laisser le MJ narrer.

## Confidentialité
La clé API et la sauvegarde restent dans le `localStorage` du navigateur. Aucune donnée n'est envoyée ailleurs que vers le fournisseur choisi.
